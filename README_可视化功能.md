# 📊 名额分配分析与可视化系统

## 🎯 功能概述

这是南京大学招生助手系统新增的名额分配分析与可视化功能，能够全面分析所有可能的名额分配方案，并以表格形式展示，帮助招生管理人员制定最优的招生策略。

## 🚀 快速开始

### 1. 启动应用
```bash
cd front_end
python app.py
```

### 2. 访问页面
- 主页：http://localhost:5030/
- 分析页面：http://localhost:5030/allocation_analysis

## 📋 功能特点

### 🔧 简化配置
- **科类选择**：只需选择文科或理科，系统自动使用预配置的专业和名额
- **自动配置**：后端提供文理科的默认招生计划和约束条件

### 📈 全面分析
- **所有方案**：生成并分析所有可能的名额分配方案
- **智能排序**：按照未满足数+滑档数总和递增排列
- **详细信息**：每个方案包含完整的录取详情

### 📊 表格展示
- **完整列表**：显示所有方案的详细对比表格
- **关键指标**：未满足数、滑档数、录取人数、录取率等
- **详情模态框**：点击查看每个方案的具体录取情况

## 🎨 界面展示

### 主要页面模块

1. **科类选择区域**
   - 文科/理科单选下拉框
   - 一键开始分析

2. **分析概览区域**
   - 当前科类显示
   - 方案总数统计
   - 学生总数
   - 招生名额总数

3. **完整方案表格**
   - 排名（按未满足+滑档总数）
   - 方案ID
   - 未满足数（黄色徽章）
   - 滑档数（红色徽章）
   - 未满足+滑档总数（重点指标）
   - 录取人数
   - 录取率
   - 名额分配情况
   - 详情查看按钮

4. **方案详情模态框**
   - 专业录取详情表格
   - 未满足承诺专业学生名单
   - 滑档学生名单

## 📖 使用流程

### 第一步：选择科类
1. 在下拉框中选择"文科"或"理科"
2. 系统自动使用对应的预配置数据

### 第二步：运行分析
1. 点击"🚀 开始分析"按钮
2. 等待系统分析所有可能方案
3. 查看分析进度提示

### 第三步：查看结果
1. **概览指标**：快速了解分析结果
2. **完整表格**：查看所有方案按优先级排序
3. **详情模态框**：点击"详情"按钮查看具体情况

## 🎯 核心优化

### 排序逻辑
- **主要指标**：未满足数 + 滑档数（越少越好）
- **最优方案**：排在第一位，用绿色高亮显示
- **直观对比**：通过颜色徽章快速识别关键数据

### 预配置数据

#### 文科配置
```json
{
  "excel_file": "2025年考生信息表-7.xlsx",
  "admission_plan": {
    "汉语言文学": 1,
    "德语(德语法学实验班)": 1,
    "经济管理试验班(数智经济与管理)": 4,
    "社会科学试验班": 5,
    "人文科学试验班": 2,
    "英语": 1
  },
  "reducible_majors": ["德语(德语法学实验班)", "英语"],
  "max_reduction": {
    "德语(德语法学实验班)": 1,
    "英语": 1
  }
}
```

#### 理科配置
```json
{
  "excel_file": "2025年考生信息表-7.xlsx",
  "admission_plan": {
    "计算机科学与技术": 3,
    "软件工程": 2,
    "电子信息类": 4,
    "数学类": 2,
    "物理学类": 1,
    "化学类": 2
  },
  "reducible_majors": ["物理学类", "化学类"],
  "max_reduction": {
    "物理学类": 1,
    "化学类": 1
  }
}
```

## 🔧 技术架构

### 后端技术
- **Flask**：Web应用框架
- **pandas**：Excel数据处理
- **student_simulation.py**：核心分析算法

### 前端技术
- **Bootstrap 5**：响应式UI框架
- **原生JavaScript**：交互逻辑
- **模态框**：详情展示

### 数据流程
1. 前端发送科类选择
2. 后端根据科类获取预配置
3. 加载对应的Excel数据
4. 执行全面分析算法
5. 按照核心指标排序
6. 返回完整的分析结果

## 📱 响应式设计

- 支持桌面端、平板、手机等多设备访问
- 表格支持横向滚动
- 模态框自适应屏幕尺寸
- 导航栏响应式布局

## 🛠️ 扩展性

### 新增科类
- 在后端配置中添加新的科类数据
- 前端下拉框自动适配

### 自定义指标
- 可在排序逻辑中调整权重
- 支持添加新的评估维度

### 数据源扩展
- 支持不同格式的Excel文件
- 可配置不同的文件路径
