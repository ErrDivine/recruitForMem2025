# 南京大学招生助手系统

这是一个基于 Flask 的智能招生助手系统，专注于名额分配分析和招生数据管理。

## 🌟 系统特色

- **🎨 现代化设计** - 采用 Apple Design System 玻璃质感风格
- **📊 智能分析** - 专业的名额分配算法，生成最优录取方案
- **📤 便捷上传** - 支持 Excel 格式考生数据文件上传
- **🔍 数据洞察** - 全面的招生数据统计和分析
- **🚀 即开即用** - 一键启动，无需复杂配置

## 💡 核心功能

### 📋 名额分配分析
- 智能分析招生方案，生成完美录取方案
- 支持多种分配策略和调整方案
- 详细的专业录取统计
- 未满足学生和滑档学生分析
- 调剂分配优化建议

### 📊 数据管理
- Excel 文件上传支持
- 考生信息自动解析
- 实时数据统计展示
- 安全的临时文件处理

## 🖥️ 系统预览

系统采用现代化的玻璃质感设计，提供直观的操作界面：

- **首页** - 功能概览和快速访问入口
- **名额分配分析** - 专业的分析工具和结果展示
- **文件上传** - 简单的拖拽上传体验

## 🛠️ 环境要求

- Python 3.8+
- 现代浏览器（Chrome、Firefox、Safari 等）
- 4GB+ 内存（推荐）

## 📦 安装步骤

### 方式一：一键启动（推荐）

```bash
# 1. 下载项目文件
# 2. 双击运行启动脚本
python start.py
```

### 方式二：手动安装

```bash
# 1. 创建虚拟环境（推荐）
python -m venv venv

# 2. 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动系统
python front_end/app.py
```

## 📋 数据文件格式

### 考生信息文件要求

创建 Excel 文件（.xlsx 或 .xls），包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 姓名 | 考生姓名 | 张三 |
| 排名 | 考生排名 | 100 |
| 意向专业 | 意向专业列表 | 1-001-1-人文科学试验班<br>1-001-2-汉语言文学 |
| 承诺专业 | 承诺录取专业 | 1.人文科学试验班<br>2.汉语言文学 |
| 是否接受调剂 | 调剂意愿 | 是/否 |

### 数据格式示例

```
姓名    排名    意向专业                        承诺专业
张三    100     1-001-1-人文科学试验班          1.人文科学试验班
李四    150     1-002-1-汉语言文学              1.汉语言文学
王五    200     1-001-1-人文科学试验班          1.人文科学试验班
```

## 🚀 使用指南

### 快速开始

1. **启动系统**
   ```bash
   python start.py
   ```

2. **访问系统**
   - 浏览器自动打开 http://localhost:5021
   - 或手动访问该地址

3. **上传数据**
   - 点击"考生信息管理"卡片
   - 选择并上传Excel文件
   - 系统自动解析和验证数据

4. **进行分析**
   - 点击"名额分配分析"
   - 配置招生计划
   - 查看分析结果

### 分析功能详解

#### 🏆 完美录取方案
- 无未满足学生
- 无滑档学生  
- 名额完全分配

#### 📊 基础方案数据
- 各专业录取统计
- 未满足学生详情
- 滑档学生分析
- 调剂分配记录

#### 💡 优化建议
- 名额调整建议
- 调剂策略优化
- 录取效率提升
